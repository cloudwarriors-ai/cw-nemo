## Weekly Software Application Health Check-Ups

**Purpose:**
* Make sure application is functioning cohesively and as planned
* Make sure there are no issues highlighted during a weekly test run which we are not aware of or would prevent an update to be made to an application on Thursday night
* Run through tests as though we are a customer walking through the application (not replace automated testing) to make sure things are functioning as intended
